# Perceptrón Multicapa implementado en C++ desde 0

```Christian David Sánchez Sánchez • Ingeniería en Computación Inteligente • 7mo B```

Este repositorio incluye una implementación de un perceptrón multicapa implementado en C++ para lograr comprender el proceso al 100% sin utilizar ningún tipo de librería externa.

En el directorio ```include/``` podremos encontrar la implementación de todas las estructuras y algoritmos, mientras que en el archivo ```main.cpp``` donde orquesto todo.
